# ─────────────────────────────
#  Fixed binary-wheel versions
#  to keep PyTorch ⇄ NumPy ABI
#  compatibility
# ─────────────────────────────
# PyTorch 2.2 is built against NumPy 1.x; using NumPy 2 disables
# the C-API inside PyTorch and breaks torch.from_numpy (see error).
# Therefore we pin NumPy to the last 1.x release and align every
# downstream library that depends on it.
